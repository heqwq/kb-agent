# 数据分析口径与常用指标

## 1. 订单与 GMV

分析库 `analytics.db` 的 `orders` 表记录订单号、区域、渠道、金额、创建时间和状态。**GMV 统一按 `status = 'paid'` 的订单金额求和**，不包含退款、待支付与已取消订单。做同比或占比时，分母使用同一时间范围、同一状态口径的 GMV。

区域字段取值为华东、华北、华南、西南；渠道字段取值为天猫、京东、抖音、线下、企业直销。月份筛选使用 `created_at LIKE 'YYYY-MM%'`，不要用字符串前缀猜测日期格式。

## 2. 常用派生指标

| 指标 | 计算方式 |
| --- | --- |
| 客单价 | 已支付订单金额之和 / 已支付订单数 |
| 退款率 | 退款订单数 / 全部订单数 |
| 渠道占比 | 该渠道已支付 GMV / 全部已支付 GMV |
| 区域占比 | 该区域已支付 GMV / 全部已支付 GMV |

百分比结果保留两位小数。需要中间过程时，先分别查出分子和分母，再用计算器求比率，避免在自然语言里心算。数据更新时间为每日 06:00，T+1 口径；临时补数需在报表中注明。分析结果用于经营参考，正式财务口径以月结报表为准。
