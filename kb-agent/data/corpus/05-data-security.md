# 数据安全与权限规范

## 1. 数据分级

公司数据分为四级：L1 公开数据，可对外发布；L2 内部数据，仅限员工访问；L3 机密数据，仅限授权项目组访问；L4 绝密数据，仅限特定岗位在受控环境处理。客户合同、源代码、未公开财务数据默认属于 L3，个人敏感信息与核心算法参数属于 L4。所有文档在创建时须标注级别，未标注的按 L2 管理。

## 2. 权限与访问

权限遵循最小必要与岗位默认原则。系统权限每季度复核一次，由数据 Owner 确认；离职、转岗或项目结束时须在 1 个工作日内回收权限。访问 L3 及以上数据须使用公司设备与 VPN，禁止在公共网盘、个人邮箱或即时通讯工具中传输。批量导出超过 500 条记录须提交数据导出申请，经数据 Owner 与安全团队审批，导出文件须加密并设置有效期。

## 3. 外发与 AI 工具

对外提供数据前须完成脱敏与法务审查。涉及 L3/L4 数据的外发必须使用公司加密邮件或受控链接，不得使用个人账号。使用外部 AI 工具时，禁止粘贴 L3/L4 数据、客户个人信息和未公开代码；确需使用生成式 AI 处理内部数据的，只能使用已通过安全评估的企业版工具，并关闭模型训练选项。

## 4. 事件响应

发现数据泄露、账号异常或设备遗失，应在 1 小时内通过安全热线 8002 或 security@xinglan.example 上报，不得自行删除日志。安全团队在 2 小时内完成初判，必要时启动应急响应。隐瞒不报或擅自处置的，按公司红线制度处理；造成客户损失的，依法追究责任。全员每年须完成一次数据安全培训与考试，未通过者暂停相关权限。
